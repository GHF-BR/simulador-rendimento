## 🇺🇸 English Version

A high-fidelity web application for simulating compound interest and calculating early retirement. The design and User Experience (UX) were built inspired by the interfaces of major fintechs and financial brokers.

🌐 **Live Demo:** [Pro Calculator - ghf-br](https://ghf-br.github.io/simulador-rendimento/)

### 🧩 Application Modules
The system is divided into two tools connected by a fluid navigation menu:

1. **Interest Projection (Compound Interest Calculator)**
   * Focused on answering: *"How much money will I have in the future?"*
   * Features an interactive stacked area chart (Chart.js) visually dividing the "invested money" from the "pure interest profit".

2. **Income Goal (FIRE - Financial Independence, Retire Early)**
   * Focused on answering: *"When will I be able to live off passive income?"*
   * Uses advanced mathematical calculations (logarithms and reverse engineering) to find the exact time (Years and Months) and the Target Amount needed to generate the user's desired monthly income.

### 🚀 Key Features
* **Real-Time Calculation:** Results and charts update instantly as the user types.
* **Input Masks:** Automatic formatting for currencies and percentages.
* **Dark/Light Mode:** Fluid and animated theme switching.
* **Smart Memory (Local Storage):** The last entered data is saved and restored automatically.
* **Native PDF Export:** Generates professional PDF reports, hiding interactive panels and adapting colors for A4 paper printing.

### 💻 How to run locally
No need to install packages (`npm` or `yarn`) or configure local servers.
```bash
git clone https://github.com/ghf-br/simulador-rendimento.git

```

*Just open the cloned folder and double-click the `index.html` file.*

## 🇧🇷 Versão em Português

Uma suíte web de alta fidelidade visual para simulação de juros compostos e cálculos de aposentadoria precoce. O design e a experiência do usuário (UX) foram construídos inspirados nas interfaces das maiores fintechs e corretoras do mercado (como Nubank, XP e BTG Pactual).

🌐 **Acesse a versão online:** [Calculadora Pro - ghf-br](https://ghf-br.github.io/simulador-rendimento/)

### 🧩 Módulos do Aplicativo

O sistema é dividido em duas ferramentas conectadas por um menu de navegação fluido:

1. **Projeção de Juros (Calculadora de Ganho Garantido)**
* Focada em responder: *"Quanto dinheiro terei no futuro?"*
* Apresenta um gráfico interativo de área empilhada (Chart.js) dividindo visualmente o valor "tirado do bolso" do "lucro puro dos juros".


2. **Meta de Renda (Independência Financeira)**
* Focada em responder: *"Quando poderei viver de renda passiva?"*
* Utiliza cálculos matemáticos de logaritmo e engenharia reversa para descobrir o tempo exato (Anos e Meses) e o Montante Alvo necessários para gerar o salário mensal desejado pelo usuário.



### 🚀 Funcionalidades Principais

* **Cálculo em Tempo Real:** Os resultados e o gráfico são atualizados instantaneamente conforme o usuário digita.
* **Máscaras de Digitação:** Formatação automática e inteligente para moedas (R$) e porcentagens (%).
* **Modo Escuro e Claro (Dark/Light Mode):** Alternância de temas fluida e animada.
* **Memória Inteligente (Local Storage):** Os últimos dados digitados são salvos e restaurados automaticamente.
* **Exportação para PDF (Nativo):** Geração de relatórios profissionais direto para PDF em papel A4.

### 💻 Como usar localmente

Não há necessidade de instalar pacotes (`npm` ou `yarn`) ou configurar servidores locais.

```bash
git clone https://github.com/ghf-br/simulador-rendimento.git
```

*Basta abrir a pasta do projeto clonado e dar um duplo clique no arquivo `index.html`.*
